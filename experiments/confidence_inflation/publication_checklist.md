# Publication checklist
- [ ] Run tests and retain the test report.
- [ ] Use at least 30 seeds for exploratory stability; consider 100+ for a final analysis.
- [ ] Inspect CSV and manifest; verify sample sizes and parameter values.
- [ ] Explain that confidence correction is estimated on calibration data only.
- [ ] Report every inflation level and all metrics, including adverse/null findings.
- [ ] Clearly label the data as synthetic.
- [ ] Add verified references and the real repository URL only after publication.
