# Publication checklist
- [ ] Run the test suite and save the test log.
- [ ] Run at least 30 seeds for exploratory stability; consider 100+ for a final study.
- [ ] Inspect CSV row counts and the run manifest.
- [ ] Describe q as a shared-shock mixture probability, not a correlation coefficient.
- [ ] Report uncertainty and identify the seed as the replication unit.
- [ ] Clearly label all data as synthetic.
- [ ] Avoid claims about real-world LLM performance or safety.
- [ ] Add verified references and the actual public repository URL before release.
