# Agent Uncertainty Wire: how AI agents report and combine confidence

**Version:** 0.3.0 · **Author:** Muzammal Hussain · **Date:** 23 October 2026  
**Runtime:** Python 3.9+; standard library only. The synthetic benchmark needs no internet or LLM; the real-model experiment needs Ollama.

## Research question

In a controlled binary-decision task with heterogeneous agents, how do simple confidence aggregation rules compare with label-only voting, and how does a separate calibration split affect team-level probabilities when reported confidence is inflated?

This is a **synthetic benchmark**, not an evaluation of real LLMs or proof that a real agent system is safe.

## Run

```bash
python3 run_all.py
python3 -m unittest discover -s tests -v
```

No `pip install` is needed. The run regenerates:

- `data/agent_messages.csv`: synthetic agent messages, calibration/test split and two confidence regimes.
- `outputs/predictions.csv`: held-out predictions for all five policies.
- `outputs/seed_summary.csv`: metrics per seed, regime and policy.
- `outputs/metrics_summary.csv`: means and between-seed standard deviations.
- `outputs/paired_policy_differences.csv`: paired differences across seeds with descriptive t intervals.
- `outputs/agent_calibration_diagnostics.csv` and `outputs/agent_reliability_bins.csv`: held-out agent-level calibration diagnostics.
- `outputs/accuracy.svg`, `outputs/brier_score.svg`, `outputs/ece.svg`: team-level metric charts.
- `outputs/agent_reliability_calibrated.svg`, `outputs/agent_reliability_overconfident.svg`: agent reliability diagrams by regime.

## Experimental design

- Five seeds; 2,500 scenarios per seed.
- Three simulated agents with different nominal skills.
- 40% of scenarios per seed reserved for calibration; 60% held out.
- Each base scenario's truth and agent predictions are paired across `calibrated` and `overconfident` confidence regimes. The latter adds 0.18 to reported confidence before clipping.
- The per-agent logistic calibrator maps reported confidence to the probability that an agent's label is correct, fitted only on calibration rows for that seed/regime/agent.

### Policies

- `label_only_majority`: average the binary labels as a soft-voting baseline, then threshold at 0.5.
- `confidence_weighted_raw`: average class probabilities implied by raw confidence.
- `confidence_weighted_calibrated`: average class probabilities implied by calibrated correctness probabilities.
- `independent_log_odds_raw`: combine signed log-odds of raw agent correctness probabilities.
- `independent_log_odds_calibrated`: combine signed log-odds of calibrated agent correctness probabilities.

The independent-log-odds rules assume a balanced class prior and conditionally independent agent errors. This assumption can fail when agents share models, prompts, data, tools or failure modes. It is a comparison baseline, not a universally correct aggregator.

## Metrics

- **Accuracy:** proportion of team labels matching synthetic truth; higher is better.
- **Brier score:** mean squared error of the predicted probability for class 1; lower is better.
- **Expected calibration error (ECE):** ten-bin, confidence-weighted gap between predicted confidence and empirical accuracy; lower is better. ECE depends on binning and is not a complete calibration diagnosis.

The paired intervals in `paired_policy_differences.csv` use differences between seed-level metrics. There are only five default seeds, so these intervals are descriptive and should not be treated as definitive population-level inference.

## Responsible interpretation

1. Rows are generated by code, not collected from people, real software agents or a public benchmark.
2. `generator_accuracy_probability` is simulator oracle metadata and would not be available at inference time in a real system.
3. The logistic calibrator can fail under distribution shift, changing reliability, small calibration samples or correlated errors. Better agent-level calibration does not guarantee better team-level probabilities.
4. Three simulated agents and binary labels do not represent tool-using LLMs or long-horizon planning.
5. Rankings depend on simulator assumptions; do not call these results real-world validation, a safety guarantee or proof that confidence-aware communication always helps.

## Experiments in this repository

| Folder | What it tests | Agents |
|---|---|---|
| `src/`, `run_all.py` | Five rules for combining three agents' confidence | simulated |
